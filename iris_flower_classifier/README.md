# 🌸 Iris Flower Classification

A Machine Learning project that predicts iris flower species using flower measurements.

## Technologies Used

* Python
* Scikit-learn
* NumPy
* Streamlit
* Matplotlib
* Seaborn

## Features

* Classification model
* Interactive Streamlit app
* Accuracy evaluation
* Confusion matrix visualization

## ML Algorithm

* K-Nearest Neighbors (KNN)
